# Citing RT-Utils

If RT-Utils contributes to published work, please cite the JOSS paper:

> Shrestha, A., A. Watkins, F. Yousefirizi, A. Rahmim, C. Uribe.
> "RT-utils: A minimal python library for RT-struct manipulation."
> *Journal of Open Source Software*, Vol. 10 (No. 107), pp. 7361, 2025.
> [doi:10.21105/joss.07361](https://doi.org/10.21105/joss.07361)

```{code-block} bibtex
:caption: BibTeX

@article{Shrestha2025,
  author  = {Shrestha, Asim and Watkins, Adam and Yousefirizi, Fereshteh
             and Rahmim, Arman and Uribe, Carlos},
  title   = {RT-utils: A minimal python library for RT-struct manipulation},
  journal = {Journal of Open Source Software},
  volume  = {10},
  number  = {107},
  pages   = {7361},
  year    = {2025},
  doi     = {10.21105/joss.07361},
  url     = {https://doi.org/10.21105/joss.07361}
}
```

The software itself also has a DOI, if you need to cite a specific version:
[10.5281/zenodo.14902966](https://doi.org/10.5281/zenodo.14902966).

## Related work

A comparison of RT-Utils against other DICOM ↔ NIfTI conversion routes is
published at
[qurit/dicom_nifti_conversion_project](https://github.com/qurit/dicom_nifti_conversion_project).

The real-world PET example from the paper is in
[`RTUTILS_read_world_example_for_PET.ipynb`](https://github.com/qurit/rt-utils/blob/main/RTUTILS_read_world_example_for_PET.ipynb).
